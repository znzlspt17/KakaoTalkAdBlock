# KakaoTalkAdBlock

AdBlocker for KakaoTalk Windows client.

## At a glance

![](https://raw.githubusercontent.com/blurfx/KakaoTalkAdBlock/main/kakaotalk.png)

This program runs in the background without a tray icon or visible window.
To quit, end `KakaoTalkAdBlock` in Task Manager. To disable an existing run-on-startup setting, use Windows Startup Apps settings.
